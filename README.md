# NEON RUSH — PWA

Application web progressive utilisable sur iPhone sans Mac.

## Mise en ligne gratuite avec GitHub Pages
1. Crée un compte GitHub si nécessaire.
2. Crée un nouveau dépôt public nommé `neon-rush`.
3. Décompresse `neon-rush-pwa.zip` et ajoute tous les fichiers du dossier à la racine du dépôt.
4. Dans Settings > Pages, choisis `Deploy from a branch`, la branche `main` et le dossier `/ (root)`, puis sauvegarde.
5. Attends la publication. GitHub affichera une adresse du type `https://TON-PSEUDO.github.io/neon-rush/`.
6. Ouvre cette adresse dans Safari sur l'iPhone > bouton Partager > Ajouter à l'écran d'accueil.

## Fonctionnalités
- 5 séances prédéfinies et personnalisables dans le code.
- Saisie séparée de chaque série, conseils contextuels.
- Historique et export CSV.
- Journal de notes et photos locales.
- Mode PWA avec cache hors ligne après le premier chargement.

## Données et limites
Les données sont enregistrées dans le stockage local du navigateur. Elles ne sont pas synchronisées entre appareils et peuvent être perdues si les données du site sont effacées. Le journal photo n'est pas un coffre-fort sécurisé. Exporte régulièrement tes données.
Le contenu nutritionnel est général : aucun calcul de calories, objectif de perte de poids ou prescription médicale.
